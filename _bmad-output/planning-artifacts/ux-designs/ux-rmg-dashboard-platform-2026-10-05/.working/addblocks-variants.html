Dashflow · “Add blocks” panel: two layout explorations

Static explorations of the right-hand Add blocks panel. Both keep the dashboard visible and usable behind a light scrim (it is a side sheet, not a modal) and both use the same Block Library content. Hover over any card or tile to see the live :hover states; the frozen frames show the same states for review.

Variant 1

Refined list

This evolves the current mockup and does not replace it. The dense list stays the fastest way to scan names and descriptions. A small thumbnail on each card shows the block’s shape: a number, a chart or a list. Clicking a card expands it in place into a real preview with sample data, so users can judge a block without leaving the panel. Search, highlighting and a clear empty state keep a large library manageable.

Trade-off: it is fast and familiar, and it fits many blocks on screen. But the thumbnails are too small to tell similar charts apart until a card is expanded.

Keyboard & accessibility

Adding a block without dragging
  1. Open the panel with the + Add block button, or press ⌘K from the dashboard.
  2. Type to filter, then ↓ to move into the results.
  3. Enter on a card opens its Preview. A (or Tab to the + Add button and Enter) adds it. The block goes to the end of the dashboard, and a polite live region says “Revenue vs Expense added at the end of your dashboard”.
  4. To change its position, use the block’s “Move” menu on the dashboard (Move up / down / to top). Drag is never the only way.
Focus order
  1. Close (×)
  2. Search field (gets focus when the panel opens; ⌘K returns here from anywhere)
  3. Category chips: one tab stop, ←/→ move between them
  4. Filter
  5. Block list: one tab stop (roving tabindex); ↑/↓ move card to card; Tab inside a card reaches its Add/Remove button
  6. Footer: Edit layout hint link, then Done
Also
  • The panel is role=dialog aria-modal=false. Focus is not trapped, F6 moves between the dashboard and the panel, and Esc closes the panel and returns focus to + Add block.
  • Added and Remove are real buttons with full labels (“Remove Calendar from dashboard”). Remove appears on :hover and :focus-within, so keyboard users get it too.
  • A locked block exposes “required by your admin and cannot be removed” and has no Remove button.
  • Thumbnails are decorative (aria-hidden). The name and description carry the meaning. The result count is announced (aria-live=polite).
  • State never relies on colour alone: there is always a check, a lock or a text label. The focus ring is 3px #2563EB.

States in this variant: default list · thumbnails · New badge · Added · hover → Remove · keyboard focus · expanded Preview with sample data and metadata · search results with highlight · empty search · mandatory (locked) · non-blocking dim.

Variant 2

Visual gallery

This variant is built for discovery. A 2-column grid of larger preview tiles, grouped under category headers, lets users recognise a block by how it looks instead of reading about it. The search and chips stay sticky while the gallery scrolls. A quick-look popover on hover or focus shows a sample-data preview and the data source. Multi-select lets users set up a new dashboard in one pass, and an Undo toast says exactly where the new blocks went.

Trade-off: previews are richer and setup in bulk is quicker. But about half as many blocks fit per screen, and the quick-look popover covers part of the dashboard.

Keyboard & accessibility

Adding a block without dragging
  1. Focus a tile and press Enter: it is added straight away and the toast offers Undo.
  2. Several at once: press Space on each tile to toggle its selection, or turn on select mode with S. The footer button updates live to “Add 3 blocks”; press Enter on it.
  3. Quick look opens when a tile gets focus, after a 400 ms delay. It is tied to the tile by aria-describedby, so screen readers hear the description and data source without moving focus. Esc dismisses it.
  4. New blocks land at the end of the dashboard. “Show me” in the toast scrolls there and moves focus to the first new block.
Focus order
  1. Close
  2. Search (sticky; autofocused)
  3. Category chips: one tab stop with arrow keys (they jump to that group’s header rather than hiding the others)
  4. Gallery: a 2-D grid with roving tabindex; ←↑→↓ move between tiles, Home/End jump
  5. “Select several” toggle
  6. Sticky footer: Done, or Add N blocks in select mode
  7. Toast (Undo) on the dashboard is reached by F6. It stays until it is dismissed while focused, and lasts 10 s minimum otherwise
Also
  • The panel is aria-modal=false with no focus trap, and the dashboard stays operable. Esc closes the panel and focus returns to the trigger.
  • Tiles are labelled “Revenue vs Expense, Charts, not added”. Group headers are real headings, so screen-reader users can jump by heading.
  • Hover and focus look the same, and the quick look never needs a pointer.
  • Selected state uses both a check mark and a ring, never colour alone. The Undo toast is announced politely and is never auto-dismissed while it has focus.
